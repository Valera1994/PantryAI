# PantryAI — интеллектуальный помощник по продуктам и рецептам

## 1. Общая информация о проекте

**PantryAI** — веб-приложение, предназначенное для управления домашними запасами продуктов и получения рекомендаций по приготовлению блюд с использованием искусственного интеллекта.

Сервис позволяет пользователю вести список имеющихся продуктов, добавлять их с помощью текстовых команд на естественном языке и получать рекомендации по рецептам с учётом своих предпочтений.

Для генерации рецептов используется локальная языковая модель Gemma 3 4B, запускаемая посредством Ollama и интегрированная в приложение с помощью Spring AI.

**Цель проекта:** разработать веб-сервис, который упрощает управление домашними запасами продуктов и помогает пользователю выбирать блюда для приготовления.

## 2. Функциональные возможности

В приложении реализованы следующие возможности:

### 2.1. Управление продуктами

- Добавление продуктов в список.
- Просмотр имеющихся продуктов.
- Редактирование информации о продуктах.
- Удаление продуктов.
- Хранение информации о продуктах в базе данных H2.

Для каждого продукта сохраняются название, количество, единица измерения и уникальный идентификатор.

### 2.2. Добавление продуктов с помощью текстовых команд

Пользователь может вводить команды обычным языком, например: «Добавь 2 кг картофеля».

Сервис обрабатывает текстовую команду и определяет название продукта, количество и единицу измерения.

Перед сохранением пользователь может проверить распознанные данные и подтвердить добавление.

### 2.3. Генерация рецептов

Пользователь может указать:
- желаемый тип блюда;
- предпочитаемую кухню;
- дополнительные пожелания.

Сервис формирует запрос для языковой модели с учётом списка продуктов и предпочтений пользователя.

Если список продуктов пуст или необходимых ингредиентов недостаточно, приложение всё равно может предложить рецепт и указать ингредиенты, которые потребуется приобрести.

### 2.4. Пользовательский интерфейс

Веб-интерфейс предоставляет средства управления продуктами, ввода команд и пожеланий к рецептам, а также отображения результатов работы искусственного интеллекта.

Для улучшения пользовательского опыта реализована анимация персонажа-повара во время ожидания генерации рецепта.

## 3. Архитектура приложения

Приложение построено на основе многоуровневой архитектуры с разделением ответственности между контроллерами, сервисами, репозиториями и моделями данных.

В проекте используется подход MVC (Model-View-Controller) с выделением отдельного сервисного слоя и слоя доступа к данным.

### 3.2. Описание компонентов

**Пользовательский интерфейс**

Реализован с использованием HTML, CSS и JavaScript. Обеспечивает взаимодействие пользователя с приложением, ввод данных, отправку HTTP-запросов и отображение результатов.

**Контроллеры (Controller)**

Контроллеры принимают HTTP-запросы и передают их соответствующим сервисам.

В проекте реализованы:

- `HomeController` — обработка перехода на главную страницу.
- `ProductController` — обработка запросов на получение и управление продуктами.
- `ProductCommandController` — обработка текстовых команд пользователя.
- `RecipeController` — обработка запросов на генерацию рецептов.

**Сервисный слой (Service)**

Содержит основную бизнес-логику приложения.

- `ProductCommandService` — обработка текстовых команд и подготовка данных о продуктах.
- `RecipeService` — получение списка продуктов, формирование запросов к языковой модели и получение рекомендаций по рецептам.

**Слой доступа к данным (Repository)**

`ProductRepository` обеспечивает взаимодействие с базой данных посредством Spring Data JPA.

**Модель данных (Model)**

`Product` представляет сущность продукта и содержит следующие поля:

- `id` — уникальный идентификатор;
- `name` — название продукта;
- `quantity` — количество;
- `unit` — единица измерения.

**Компонент искусственного интеллекта**

Spring AI обеспечивает интеграцию серверного приложения с языковой моделью Ollama. Модель Gemma 3 4B используется для обработки текстовых запросов и генерации рецептов.

## 6. Применённые архитектурные решения и паттерны

В проекте применены следующие архитектурные решения:

**MVC (Model-View-Controller)**

Разделение приложения на модель данных, контроллеры и представление.

**Repository**

Использование `ProductRepository` для отделения операций доступа к базе данных от бизнес-логики приложения.

**Service Layer**

Вынесение основной бизнес-логики в отдельный сервисный слой.

**Dependency Injection (внедрение зависимостей)**

Использование механизмов Spring для создания объектов и передачи необходимых зависимостей между компонентами.

**ORM (Object-Relational Mapping)**

Связывание Java-объектов с таблицами базы данных с помощью JPA и Hibernate.

## 11. Итоговый вывод

В результате выполнения курсового проекта разработан веб-сервис PantryAI, предназначенный для управления домашними запасами продуктов и интеллектуального подбора рецептов.

В ходе работы реализованы основные функции управления продуктами, обработка текстовых команд пользователя, хранение информации в базе данных и интеграция локальной языковой модели для генерации рецептов.

Разработанное приложение объединяет возможности классического веб-сервиса и технологий искусственного интеллекта.

Поставленная цель курсового проектирования достигнута: создан работающий прототип интеллектуального помощника, позволяющий пользователю управлять списком продуктов и получать рекомендации по приготовлению блюд.

В дальнейшем приложение может быть расширено за счёт улучшения качества генерации рецептов, развития голосового управления и добавления новых пользовательских возможностей.

При создании работы использовались браузерные версии ИИ агентов ChatGPT для создание базовой структуры проекта, а Qwen3.7 для настройки зависимостей и по вопросам интеграции с языковой моделью.
